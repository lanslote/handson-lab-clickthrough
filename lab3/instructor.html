새 수업 만들기

운영자가 설정한 8자 이상의 강사 비밀번호를 입력하세요. Azure 운영자는 Portal → Function App → 설정 → 환경 변수의 LAB3_ADMIN_KEY 값을 확인할 수 있습니다. 수강생에게 공유하거나 URL에 넣지 마세요. 처음에는 모든 구간이 닫혀 있습니다.

기존 수업 관리 복구

이 수업의 강사 복구 키를 사용하세요. 수강생 개인 키로는 관리 권한을 얻을 수 없습니다.

내 강사 복구 정보 (새 기기에서 관리 계속하기)

강사 키는 수업 제어 권한을 가집니다. 수강생에게 공유하지 마세요. 공용 PC에서는 수업 후 나가기를 누르세요.

수강생 초대

수강생 입장 주소:

수업 코드 ·

위 수강생 주소와 수업 코드만 공유하세요. 강사 화면 주소나 강사 복구 키는 초대 정보가 아닙니다.

완료 인원은 실제 활동 완료 기록입니다. 화면을 열었다고 완료되지 않으며, 전원 완료되어도 자동 개방하지 않습니다. 닫기는 신규 입장만 막습니다.
